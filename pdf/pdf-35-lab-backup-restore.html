Execute

Backup · Destroy

01 / Back Up Offline

docker compose stop jenkins docker run --rm \ -v jenkins-lab_jenkins_home:/data \ -v "$PWD":/out alpine \ tar czf /out/jenkins-backup.tar.gz -C /data . docker compose start jenkins

WHY OFFLINE — stopped controller = consistent snapshot; live copies risk half-written state.

Record one job's build number + one credential ID — the restore proof.

02 / Destroy and Restore

docker compose down -v # everything, incl. volume docker compose up -d # fresh controller docker compose stop jenkins docker run --rm \ -v jenkins-lab_jenkins_home:/data \ -v "$PWD":/in alpine \ tar xzf /in/jenkins-backup.tar.gz -C /data docker compose start jenkins
