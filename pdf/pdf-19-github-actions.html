Mechanics

Runners · Cost · Patterns

04 / Runners & Cost

  • Labels select runners — wrong labels = queue forever.
  • Trust — fork PRs never touch persistent self-hosted runners.
  • Cost — public free; private pool 2–3k min/mo; then ~$0.006 Linux / $0.010 Windows / $0.062 macOS. macOS burns 10×.
  • Killers — macOS builds, no cache, sprawling matrices, failed jobs bill like green ones.

05 / Power Patterns

REUSABLE (workflow_call) — one pipeline, N repos. MATRIX — fan out versions in one block. CONCURRENCY — cancel stale runs. PATHS — docs-only PRs skip CI. SETUP — drop the YAML, push, watch Actions tab, require the check in branch protection.
ARC SCALE SET — ephemeral runners on your cluster, scale-to-zero idle, burst to max on PR storms. Remote caches (not pod disks). Wins when hosted minutes cost more than cluster ops.

06 / Actions vs Jenkins

ActionsJenkins
RunsGitHub cloud, fresh VMYour servers
LanguageYAML in repoGroovy Jenkinsfile
CostFree pool, then meterFree license + your labor

One line: Actions trades control for convenience; Jenkins trades convenience for control.

Q: needs: vs parallel?
A: Jobs run parallel by default; needs: sequences them into gates.
