Choice

Delivery vs Deployment

02 / When Each

  • Delivery (human gate) — regulated industries, data migrations, coordinated launches, teams still building gate maturity.
  • Deployment (no gate) — SaaS with progressive delivery, strong SLOs, practiced rollback, trunk discipline. Start low-risk, expand as confidence compounds.

03 / Failure Modes

AUTOMATING A FLAKY PIPELINE ships bugs at machine speed — fix gates first, automate second. NO KILL CRITERIA lets bad releases reach 100% "successfully". NAIVE MIGRATIONS corrupt state — expand-contract only. ON-CALL DISTRUST re-adds manual gates — boring, practiced rollbacks build the confidence.
Q: The one-gate difference?
A: Delivery stages with human approval; Deployment promotes automatically. Same pipeline, different trust.
