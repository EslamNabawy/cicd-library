01 / Run & Unlock

$ docker volume create jenkins_home $ docker run -d --name jenkins \   -p 8080:8080 -p 50000:50000 \   -v jenkins_home:/var/jenkins_home \   -v /var/run/docker.sock:/var/run/docker.sock \   jenkins/jenkins:2.516-lts-jdk17 $ docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword

Open localhost:8080 → paste the password → install suggested plugins → create admin user → set built-in executors to 0.

Seven Steps

Run · Use · Verify

04 / Run & Use, End to End

1 · Run — container + volume + socket (above).
2 · Unlock — password, suggested plugins, admin user.
3 · Lock controller — built-in executors = 0.
4 · Agent — new node linux-1, labels linux docker, idle in Executor Status.
5 · Multibranch job — repo URL + credentials; Jenkinsfile discovered per branch.
6 · Webhook — /github-webhook/; push → build in seconds.
7 · Verify loop — green → staging → approve → production. Break it on purpose once.

Checklist · Failures

05 / Production Checklist

  • Persistent, backed-up JENKINS_HOME (test restore).
  • Pinned image + plugin versions; deliberate upgrades.
  • TLS reverse proxy + auth matrix from day one.
  • Lost data on recreate = volume wasn't mounted. Port 50000 blocked = agents can't connect.
