02 / Placement Rules

  • PR: unit + contract + fast integration (< 10 min total). Slower moves post-merge.
  • Staging: full integration + E2E + smoke; failures block promotion, not merges.
  • Post-deploy: synthetic smoke probes — the pipeline's last test never ends.

03 / Flaky Protocol

QUARANTINE — move to a non-blocking suite same day · assign an owner · fix-or-delete within one sprint. A flaky gate teaches developers that red is meaningless — the most expensive test debt there is.
Q: E2E in PR pipelines?
A: No — 40-minute suites get ignored. Move E2E to staging; keep PR under 10 minutes.
