01 / Staging Auto-Deploys

deploy-staging: needs: image environment: staging runs-on: ubuntu-latest steps: - run: echo "deploy DIGEST to staging"

EXPECT — every main merge deploys staging, no clicks.

Safe to automate: users never see it.

02 / Production Needs a Human

EXECUTE — add deploy-prod with environment: production (required reviewer in Settings → Environments).

Production waits; after approval it runs the same digest. This is Continuous Delivery's one gate.
