01 / 03 · THE SMALLEST CLOSED LOOPNabawy
Labs   Lab 01

Execute

Workflow · Gate

01 / Add the Workflow

# .github/workflows/ci.yml name: ci on: { push, pull_request } jobs: build: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: actions/setup-node@v4 with: { node-version: 20, cache: npm } - run: npm ci - run: npm test

EXPECT — green run in Actions tab, green check on the PR.

Push to a branch, open a PR. Trigger → runner → job → feedback: the smallest closed loop.

02 / Require the Check

EXECUTE — Settings → Branches → protect main → require build.

Push a breaking change: the merge button blocks until green. An unenforced gate is decoration.

01 / Build Once, Tag SHA

- uses: docker/login-action@v3 with: { registry: ghcr.io, ... } - uses: docker/metadata-action@v5 with: images: ghcr.io/OWNER/APP tags: type=sha,prefix=sha- - uses: docker/build-push-action@v6 with: { push: true }

SHA = immutable identity; the digest is what every environment deploys — never :latest.

LAB 05
ROLLBACK

Break production — recover in minutes
OLD DIGESTS · TIMED RECOVERY
POSTMORTEM WITH TEETH
01 / 03 · RECOVERY, PRACTICEDNabawy
Labs   Lab 05

Execute

Incident · Recover

01 / Cause the Incident

EXECUTE — merge a change that passes tests but breaks visible output (wrong port, broken route). Promote to production.

Green ≠ correct. This is why recovery is engineered, not improvised.

02 / Roll Back, Don't Rebuild

EXECUTE — redeploy the previous digest (re-run old deploy-prod). Time yourself.

Old digests are proven in production; fresh builds add untested variables to a fire.

03 / Postmortem With Teeth

WRITE — timeline + root cause + one action item that becomes a merged pipeline change (new test, check, or alert). Postmortems without merged changes are diary entries.

Execute

Agent · Pipeline

01 / Connect the Agent

docker compose up -d docker exec jenkins cat \ /var/jenkins_home/secrets/initialAdminPassword

EXPECT — node agent-1 online, label docker-agent, 2–4 executors.

Create the node in Manage Jenkins → Nodes, launch inbound with the secret. Controller schedules, agents execute.

02 / Run the Canonical Pipeline

pipeline { agent { label 'docker-agent' } stages { stage('Build') { steps { sh 'echo build' } } stage('Test') { steps { sh 'echo test' } } stage('Deploy'){ steps { echo 'deploy' } } } }

EXPECT — three green boxes in Stage View, all on agent-1.

Controller runs zero builds — no executors on master, ever, in prod.

LAB 07
SHARED LIBRARY

One step defined — two pipelines consuming
VARS/ · VERSION PIN
DRY WITH A SAFETY RAIL
01 / 03 · REUSE WITHOUT COPY-PASTENabawy
Labs   Lab 07

Execute

Register · Consume

01 / Register the Library

# pipeline-library repo, vars/standardTest.groovy def call(Map cfg = [:]) { sh "${cfg.cmd ?: 'npm test'}" }

EXECUTE — Manage Jenkins → System → Global Pipeline Libraries → add my-lib, version main.

Versioned libraries are dependencies: pinned, reviewed, rollback-able.

02 / Consume From Two Pipelines

@Library('my-lib') _ pipeline { agent { label 'docker-agent' } stages { stage('Test') { steps { standardTest(cmd: 'npm test') } } } }

EXPECT — both pipelines green on the shared step.

One definition, N consumers — the DRY payoff, version pin as safety rail.

LAB 08
BACKUP + RESTORE

Destroy the controller — bring it back
OFFLINE SNAPSHOT · FULL WIPE
RESTORE · SMOKE REPLAY
01 / 03 · RECOVERY MEASURED, NOT ASSUMEDNabawy
Labs   Lab 08

Execute

Backup · Destroy

01 / Back Up Offline

docker compose stop jenkins docker run --rm \ -v jenkins-lab_jenkins_home:/data \ -v "$PWD":/out alpine \ tar czf /out/jenkins-backup.tar.gz -C /data . docker compose start jenkins

WHY OFFLINE — stopped controller = consistent snapshot; live copies risk half-written state.

Record one job's build number + one credential ID — the restore proof.

02 / Destroy and Restore

docker compose down -v # everything, incl. volume docker compose up -d # fresh controller docker compose stop jenkins docker run --rm \ -v jenkins-lab_jenkins_home:/data \ -v "$PWD":/in alpine \ tar xzf /in/jenkins-backup.tar.gz -C /data docker compose start jenkins
