Secrets · Signing
26
HIGHEST-VALUE TARGET

Picking up from Environments & Release — the pipeline holds deploy keys, signs releases, and runs attacker-influenced PR code. It is the highest-value target in the estate.

01 / Secrets Discipline

  • Managers only (Vault, KMS, Jenkins store, GitHub environments) — never repos, images, logs, chat.
  • Scope per-env per-job, rotate on schedule and on any leak, audit every access.
  • Fork PR builds get zero production secrets — credential-free sandboxes only.

03 / Least Privilege + Pinned Chain

TOKENS — per-repo, minimal scopes, short TTL. OIDC federation (workloads mint credentials) beats long-lived keys nobody rotates. HUMANS — SSO + MFA, matrix authorization, no shared admins.
PIN EVERYTHING — action SHAs not @v4 · image digests not :latest · plugin versions · lockfiles. Verify checksums on download. Dependency-bump PRs are untrusted code until the gate proves otherwise.
Q: Secret lands in git history?
A: Rotate immediately — history rewrites do not unsee it; it is cloned everywhere.
