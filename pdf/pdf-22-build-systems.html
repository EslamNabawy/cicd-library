Picking up from CI/CD Pipelines, where the build stage was defined — here is what runs inside it. A build system must be hermetic: sealed from the ambient machine.

01 / Hermetic Rules

SEALED — pinned deps via lockfiles (package-lock.json, go.sum, POM versions) · clean container per build · no latest tags · no host toolchains. Symptom of violation: builds that pass in CI and fail locally — or the reverse.
# CI, not local: exact, not approximate npm ci # lockfile-exact, never npm install ./gradlew build # wrapper pins the toolchain itself

02 / Caching Done Right

  • Dependency cache keyed on lockfiles — stale key ships stale code silently.
  • Remote build cache (Gradle remote, BuildKit registry cache) for compiled layers.
  • Skip rebuild when inputs are unchanged.
