LAB 06
JENKINS LIVE

Controller + agent in Compose, first pipeline
DOCKER COMPOSE · INBOUND AGENT
THREE GREEN STAGES
01 / 03 · SCHEDULE HERE, EXECUTE THERENabawy

01 / Connect the Agent

docker compose up -d docker exec jenkins cat \ /var/jenkins_home/secrets/initialAdminPassword

EXPECT — node agent-1 online, label docker-agent, 2–4 executors.

Create the node in Manage Jenkins → Nodes, launch inbound with the secret. Controller schedules, agents execute.

02 / Run the Canonical Pipeline

pipeline { agent { label 'docker-agent' } stages { stage('Build') { steps { sh 'echo build' } } stage('Test') { steps { sh 'echo test' } } stage('Deploy'){ steps { echo 'deploy' } } } }

EXPECT — three green boxes in Stage View, all on agent-1.

Controller runs zero builds — no executors on master, ever, in prod.

03 / Verification

  • Agent online, labeled, idle after the run.
  • Three green stages; controller executors at zero.
  • Trouble: agent offline → secret/URL wrong; use http://jenkins:8080 in-Compose.

Proved: the controller/agent split hands-on. Next: Lab 07 · Shared Library.
